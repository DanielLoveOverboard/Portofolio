# TIMELESS UI — DESIGN SYSTEM

## Philosophy
Timeless treats interface design as information architecture made visible.

Ask: "What is the fastest, clearest way for the user to understand and act?"

## Four principles
**Legibility** — understand before admire.
**Directness** — actions look like actions.
**Structure** — hierarchy comes from layout, type, and borders.
**Durability** — avoid short-lived visual trends.

## Personality
Inspired by editorial layouts, technical documentation, operating-system utilities,
Swiss information hierarchy, and early-web brutalism. It is not a literal retro UI.

## Surface model
Only two surface states exist:
- base
- inverted

Light = white base / black inverted.
Dark = black base / white inverted.

## Hierarchy
Position → scale → weight → spacing → border → inversion → iconography.
