# TIMELESS UI v1.0

A universal, function-first, monochrome web UI system.

Timeless is intentionally the visual opposite of decorative UI systems:
flat, shallow, rectangular, legible, predictable, fast, and durable.

Suitable for SaaS, dashboards, admin tools, education, finance, documentation,
developer tools, media, e-commerce, portfolios, game interfaces, utilities,
internal tools, and experimental websites.

## Core rule

> Function first. Decoration only when it improves function.

Exactly two tones are used at a time.

Light mode:
- White #FFFFFF
- Black #000000

Dark mode:
- Black #000000
- White #FFFFFF

No gray palette, accent colors, gradients, glass, glow, or colored shadows.

For AI agents, read `AGENT_RULES.md` first.
